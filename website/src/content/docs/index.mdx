## Features

<CardGrid>
  <Card title="One sidebar, every pane" icon="list-format">
    Tracks Claude Code, Codex, and OpenCode panes across every tmux session and window at
    once, so context switching stops meaning window switching.
  </Card>
  <Card title="Stable, compact agent list" icon="comment-alt">
    Creation-order rows, a persistent active-agent highlight, optional hidden
    previews, task progress, and activity without tab clutter.
  </Card>
  <Card title="Worktree-aware" icon="seti:folder">
    Spawn a fresh worktree + agent from the sidebar, and tear it down —
    window, worktree, and branch — in a single keystroke.
  </Card>
  <Card title="Desktop notifications" icon="signal">
    Short notifications for new completions, questions, permissions, and errors.
    On Hyprland, visible agent windows do not trigger redundant desktop alerts.
  </Card>
</CardGrid>

## Quick start

Using [TPM](https://github.com/tmux-plugins/tpm):

```bash
set -g @plugin 'ahmad9059/AgentsTmux'
```

Reload with `tmux source ~/.tmux.conf`, press `prefix + I` to install, and the
install wizard downloads a pre-built binary or builds from source.

Next, wire up your agent hooks — [Claude Code](/AgentsTmux/getting-started/claude-code/)
installs as a plugin, [Codex](/AgentsTmux/getting-started/codex/) is a
one-paste setup inside its own pane, and [OpenCode](/AgentsTmux/getting-started/opencode/)
uses the bundled plugin bridge.
